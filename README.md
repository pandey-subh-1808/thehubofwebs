# pandey-subh-1808 — Project & Code Hub

A personal code vault and project launcher built as a single-file HTML web application (`index.html`) with a frosted-glass, pastel violet-and-mint UI[cite: 2]. It organizes your repositories, links directly to your hosted HTML pages on GitHub Pages, lets you inspect or preview code, and supports adding new projects over time.

## Key Features

* **Direct HTML Launching:** Dedicated quick-launch strip and **Open HTML** buttons on cards with live demo URLs.
* **Code Viewer & Live Preview:** Syntax-highlighted code modal with copy/download actions and a sandboxed live preview tab for HTML snippets.
* **Add, Edit & Pin Projects:** Click **+ Add Project** to paste code or upload a local file (`.html`, `.py`, `.js`, etc.) for future builds.
* **Search & Filtering:** Filter by keyword, programming language, or pinned status.
* **Local Persistence & JSON Backup:** Changes save automatically in `localStorage`, with **Export JSON** and **Import JSON** buttons for portable backups across browsers or devices.

## Deployment on GitHub Pages

1. Add `index.html` (and this `README.md`) to your GitHub repository under `pandey-subh-1808`[cite: 1].
2. Open **Settings → Pages** in your repository.
3. Set the source branch (e.g., `main`) and root folder (`/`) and save.
4. Your hub will be available at your GitHub Pages URL. Whenever you add new projects, click **Export JSON** to keep a backup copy.
